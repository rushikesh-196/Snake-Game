# 🐍 Snake Game

A simple browser-based Snake Game built with **HTML, CSS, and JavaScript**. The repository contains the page structure, styling, and game logic in separate files.

## 🎮 Project Overview

The Snake Game is a classic arcade-style game in which the player controls a snake, collects food, and tries to avoid collisions. It is a small front-end project for practising JavaScript logic and browser-based development.

## ✨ Features

- Classic Snake Game concept
- Browser-based interface
- JavaScript game logic
- HTML page structure
- CSS styling

> The exact controls, scoring system, collision rules, and restart behavior depend on the implementation in `game.js`. Update this list if your code includes additional features.

## 🧰 Technologies Used

- **HTML5** — page structure
- **CSS3** — styling and layout
- **JavaScript** — game behavior and interaction

## 📁 Project Structure

```text
Snake-Game/
├── index.html   # Main HTML page
├── style.css    # Game styling
├── game.js      # Game logic
└── README.md    # Project documentation
```

## 🚀 Run the Game Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/rushikesh-196/Snake-Game.git
   ```

2. Open the project folder:

   ```bash
   cd Snake-Game
   ```

3. Open `index.html` in a web browser.

   You can also open the folder in Visual Studio Code and use a local development server if you prefer.
